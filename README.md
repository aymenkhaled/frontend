# React Analytics Dashboard

A React dashboard UI built with Material UI, Redux Toolkit, and data-visualization components.

## What's included

The application has a dashboard route, a shared layout, and theme-aware UI. The source includes components, scenes, application state, and charting dependencies.

## Stack

- React and Create React App
- Material UI and MUI Data Grid
- Redux Toolkit
- Nivo charts
- React Router

## Run locally

```bash
npm install
npm start
```

Visit [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm test
```

## Code layout

- `src/scenes/dashboard/` — dashboard page
- `src/scenes/layout/` — navigation and page layout
- `src/components/` — reusable UI
- `src/state/` — Redux state
- `src/theme.js` — theme configuration

## Status

Portfolio / learning project. This repository currently uses Create React App and should be reviewed for dependency upgrades before production deployment. A connected production data source is not documented here.
